Certificates for "The Volume Gap at Five-Valent Vertices"
==========================================================

Each subfolder holds the scripts and outputs of one computer-assisted step. Folders
marked "copied" were copied from the research folder named below;
SOURCE_SHA256SUMS.txt in such a folder is the checksum list of its source, verified on
21 October 2026 (the 2026-10-22 folders on 22 October 2026), 0 failures. On 22 October
2026 the path strings of 17 copied scripts were changed so that they find their inputs
inside this tree instead of in the research folders; PATH_FIXES.md lists every change
(file, old string, new string), and the per-folder lists carry the new hashes of those
scripts. The stored outputs were produced by the scripts before that change; the
replays listed in PATH_FIXES.md reproduce them. Folders marked "new" were written for
the final revision of the paper and carry their own SHA256SUMS.txt. A per-folder list
may name files that are not shipped (large per-tuple outputs); these are said below.
Revision pass 2b (22 October 2026) added five files: sw/scripts/sw_even_window_exact.py,
z32rigor/scripts/tail_certify_exact.py and lj/scripts/lj_exact_slope_check.py, with their outputs; each is appended to its folder's checksum list.
The paper's own code is in ../code. The checksums of everything shipped are in
../SHA256SUMS.txt.

Kinds:
  EXACT      rational arithmetic (python-flint fmpq or Fractions), or sympy polynomial
             coefficient signs after substituting nonnegative shift variables
  INTERVAL   mpmath iv / Arb balls, or binary64 with one nextafter step outward per op
  RFLOAT     binary64 with an a priori error bound (Weyl + Higham gamma_k + Gershgorin
             + Sylvester); kernels computed exactly. The bound needs every float entry
             to approximate the exact square root of its rational squared link with
             relative error at most 2.0001u, u = 2^-53 (the unit roundoff).
             The certificates of Theorem 6.1(h) are those in rfloat_sqrt/, which compute
             each entry with math.sqrt and check this bound for it in exact rational
             arithmetic before use, so no property of the C runtime is assumed. (The
             original fc/ and rr/ runs used float(Fraction)**0.5; refA/ bounds that
             error exhaustively, worst 1.446 ulp. They are kept as the earlier runs.)

HOW TO RUN. Run every script from its own scripts/ directory, for example
    cd certificates/sl4/scripts && python vs_symbolic.py
(for a referee/ subfolder: cd <folder>/referee/scripts; for hv/, vg4/, pencil71/ and
v6proofs/, which have no scripts/ directory: cd <folder>). Many scripts write to
../outputs relative to the working directory, so running them from elsewhere fails or
writes to the wrong place. Use the interpreter that has numpy, scipy, sympy, mpmath and
python-flint (torch with CUDA only for z32rigor/scripts/run_all.sh). Scripts read no
downloaded data. Every command below was run in this form on a scratch copy on 22 October
2026 and exited with status 0; commands marked [tested smaller] were run with the
smaller arguments shown in brackets, because the full run takes long.

Appendix letters refer to the compiled paper: A four-valent multiplier, B Stark windows,
C chains at j1 = 1/2, D slice j1 = 1, E slice j1 = 3/2, F slice j1 = 2, G pencil and three
bounded legs, H valence six, I the su(2) ladder.
